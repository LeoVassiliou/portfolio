# Archive: earlier versions of the Theism Probability Engine

Kept for history. The current version is [`../index.html`](../index.html).

- `v1.html` to `v6.html`: successive iterations of the original tool
- `bayes*.html`: later experiments
- `arguments.js`: the long-form argument data (premises, evidence, objections, rebuttals) the early versions used
- `dream.html`, `logos.html`, `writings.html` and `writings/`: related experiments and personal writings

Open any file directly in a browser. Links between these files still work because they were moved together.
